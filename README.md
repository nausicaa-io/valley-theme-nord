# Nord

Frosted arctic layers: rounded inset tabs, soft controls, generous reading rhythm, and blue-grey Light and Dark surfaces.

## Installation

Install this repository through Valley's Themes settings, or download the ZIP from GitHub Releases and install the theme package. Select the theme in Appearance and choose Light or Dark. Themes are free.

## Package

`manifest.json` defines the theme identity. `theme.css` provides its appearance. Optional `config.json` declares packaged fonts, icons, and media assets. `SHOWCASE.md` contains the Community previews.
